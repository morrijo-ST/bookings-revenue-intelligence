# Forecasting Methodology — Bookings & Revenue Intelligence

## Objective
Provide a transparent bottom-up forecast that connects commercial pipeline, renewal activity, booked value, revenue stage, and documented management adjustments.

## Reference Forecast Layers
1. **Booked / actualized value** — completed commercial activity already recognized in the period.
2. **Committed value** — high-confidence future activity supported by approved commercial evidence.
3. **Pipeline value** — opportunity-stage activity subject to documented weighting or scenario assumptions.
4. **Renewal exposure** — scheduled recurring-value events expected within the forecast horizon.
5. **Management adjustments** — separately identified overlays with explicit rationale.

## Snapshot Method
Each forecast snapshot stores the reporting cut-off date so current-versus-prior movement can be explained consistently.

## Variance Analysis
Forecast variance is decomposed into identifiable drivers such as:
- new bookings
- slipped timing
- stage changes
- renewal changes
- revenue-stage movement
- management adjustment
- data correction

## Control Principles
- Actual / booked values are not overwritten by forecast logic.
- Management overlays remain separately identifiable.
- Snapshot comparisons use comparable cut-off periods.
- Material changes should be traceable to underlying customer or contract records.

> Public methodology is generalized and uses synthetic scenarios.
