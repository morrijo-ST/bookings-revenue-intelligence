# Security — Bookings & Revenue Intelligence

- Keep CRM, Snowflake, and BI credentials out of source control.
- Use least-privilege access for analytical datasets.
- Separate management adjustments from system-generated values.
- Protect customer, contract, and pipeline details through role-based access when required.
- Do not publish real customer or commercial data in portfolio artifacts.
- Preserve refresh timestamps and snapshot lineage for executive reporting.
- Review exported files before external sharing to prevent sensitive-data leakage.

This public repository is designed for synthetic examples only.
